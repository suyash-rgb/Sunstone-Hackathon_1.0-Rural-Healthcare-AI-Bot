fix: Unsafe Property Access 

accessing translations[langCode].xyz directly was the potential cause for the crash. If a user tapped Telugu/Gujarati, the app would instantly fatally crash. I have permanently patched this by routing all text through the safe getTranslation() helper.

JSBigFileString::fromPath on the app console was the actual cause for crash. 
When a user opens the app, Expo Go downloads the app's Javascript bundle over the ngrok tunnel. If the tunnel connection drops or stutters mid-download (which the terminal confirmed with Tunnel connection has been closed), the phone receives a corrupted/partial file and crashes with Could not open file:.

added @expo/ngrok dependency for tunneling and eliminating proximity limitation in dev phase and testing.
