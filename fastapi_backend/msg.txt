feat: Hybrid Fallback Healthcare Facility Discovery 
Implemented a Hybrid Fallback Service combining Ola Maps Places API with OpenStreetMap (Overpass API) fallback for emergency healthcare discovery in rural and urban areas.

Architecture Flow:

                        [ Request: lat, lon, radius ]
                                     |
                          [ Check TTL Cache ]
                         /                   \
                 (Hit)  /                     \ (Miss)
                       v                       v
               [ Return Cached ]      [ Query Ola Maps API ]
                                            /       \
                        (Success & >0 results)       (Fails / Timeout / 0 Results)
                                         /             \
                                        v               v
                             [ Return Ola Facilities ]  [ Fallback: Query Overpass OSM API ]
                                                                |
                                                      [ Compute Haversine Dist & Tier ]
                                                                |
                                                      [ Cache & Return Facilities ]

Changes Made

1. osm_service.py [NEW]
Created OSMService to execute non-blocking Overpass QL spatial queries for node and way elements tagged with amenity=hospital, amenity=clinic, healthcare=centre, or healthcare=hospital.
Added multi-mirror endpoint failover (overpass-api.de, overpass.kumi.systems, overpass.nchc.org.tw) with proper User-Agent headers to avoid HTTP 406 blocks.
Uses haversine_distance to compute precise distance in meters and km.
Classifies government facilities (PHC, CHC, District Hospital) via operator tags and name regex matching.
Assembles Google Maps navigation deep links (https://www.google.com/maps/dir/?api=1&destination=LAT,LON) for each facility card.

2. olamaps_service.py [MODIFY]
Wrapped Ola Maps calls in exception handling.
If Ola Maps fails, times out, or returns 0 results (e.g. deep rural areas), it automatically logs [Hybrid Fallback Triggered] and calls osm_service.get_nearby_facilities.
Standardized schema output using MedicalFacility Pydantic model and saved results to facility_cache.
